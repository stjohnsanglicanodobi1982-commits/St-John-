# St John's Anglican Church, Odobi Okemesi Ekiti

A modern, responsive, and reverent static website for **St John's Anglican Church, Odobi Okemesi Ekiti**, built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Features

- **Anglican Blue, White & Gold Theme**: Clean, reverent visual aesthetics reflecting traditional Anglican heritage.
- **Mobile First & Responsive**: Optimized for seamless viewing on mobile phones, tablets, and desktop displays.
- **Section Navigation**:
  - **Home**: Hero section featuring welcoming headline, "Join Us This Sunday 9am" button, and scripture verse (Psalm 122:1).
  - **About**: Concise historical context (Founded in 1982) and location details (Oke Onire Street, Odobi, Okemesi Ekiti).
  - **Services**: Sunday Worship (9:00 AM – 12:00 PM), Holy Communion, Bible Study, and Prayer Meetings.
  - **Give**: Official bank details for Tithes, Offerings, and Donations (First Bank, Account Name: St John's Anglican Church, Odobi, Account Number: 2000316772) with a one-click copy button.
  - **Contact**: Location, phone numbers (+234 706 267 6430, +234 905 918 8643), email (`stjohnsanglicanodobi1982@gmail.com`), and contact form UI.
- **St John's Assistant Chatbot**: Floating interactive widget in the bottom-right corner answering FAQs regarding Vicar, Bishop, Archdeaconry, Diocese, Province, Choir size, Membership numbers, Service schedule, and Prayer requests.
- **Footer**: Copyright 2025 St John's Anglican Church with quick navigation and contact details.

## Tech Stack

- **Framework**: React 18 + TypeScript
- **Bundler**: Vite 5
- **Styling**: Tailwind CSS + Custom CSS Variables
- **Icons**: Lucide React

## Local Development

To run the project locally on your machine:

1. Clone or download the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:5173`.

## Build for Production

To create a static production build:

```bash
npm run build
```

The output will be placed in the `dist` directory, ready for static hosting on **Netlify**.
